# Contributing

Read README.md and docs/SETUP.md before changing behavior. Keep the platform View implementation lightweight and preserve remote navigation. Open an issue with a minimal reproduction, Android version and TV model. Remove IP addresses, names, location, receiver names and private logs before sharing.

Run `./gradlew assembleDebug lintDebug`. For device changes, report app focus/launch/long press, Home, HDMI/tuner, weather off/on, and optional AirPlay start/stop checks. Do not claim compatibility with a device you have not tested. Never commit APKs, signing files or credentials.
