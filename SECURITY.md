# Security

Do not post credentials, private device logs, local network details or screenshots with personal data in public issues. For a vulnerability, use this repository's private vulnerability reporting feature if enabled; otherwise open an issue requesting a private reporting channel without exploit details.

No analytics or developer backend is used. Optional city searches and weather requests go to Open-Meteo. The manual speed test contacts Cloudflare and can download about 25 MB. The AirPlay watcher reads selected logcat tags locally and checks foreground usage; enable only when using the separate receiver and understanding its permissions. Configuration is stored in app-private preferences; Android backups are disabled.
